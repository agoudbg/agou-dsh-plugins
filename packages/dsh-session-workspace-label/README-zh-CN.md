![](icon.svg) **会话工作区标签**

侧边栏会话列表处于“单列表”模式时，在每个会话标题的下方显示所属工作区的名称。不属于任何工作区的会话显示“未分组”，工作区改名后标签会立即更新。

## 安装

需要 DSH 0.2.1-rc.5 或更高版本，并使用网页界面。

```sh
dsh plugin --profile <profile> add dsh-session-workspace-label
```

也可以克隆 [agou-dsh-plugins](https://github.com/agoudbg/agou-dsh-plugins) 仓库，在插件管理器中通过本包目录的绝对路径安装。

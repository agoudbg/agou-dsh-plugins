When the sidebar's session list is in **In one list** mode, each conversation shows its workspace name on a second line under its title. Conversations outside every workspace show **Ungrouped**, and renamed workspaces update the labels immediately.

## Install

Requires DSH 0.2.1-rc.5 or later with the Web UI.

```sh
dsh plugin --profile <profile> add dsh-session-workspace-label
```

From a local clone of [agou-dsh-plugins](https://github.com/agoudbg/agou-dsh-plugins), install this package directory through the DSH Plugin Manager instead.

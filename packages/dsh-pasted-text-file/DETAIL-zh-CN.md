粘贴超过 5000 个字符时，文本会作为文件出现在草稿旁边，你可以继续编辑消息，再把文字和附件一起发送。文件名跟随界面语言，同一会话中后续的粘贴依次编号为 (1)、(2)。

点击附件上的“粘贴到文本框”，可以把原文插回输入框的光标处，并移除这份附件。同一次粘贴里包含的文件和图片照常添加为附件。

## 安装

需要 DSH 0.2.1-rc.5 或更高版本，并使用网页界面。

```sh
dsh plugin --profile <profile> add dsh-pasted-text-file
```

也可以克隆 [agou-dsh-plugins](https://github.com/agoudbg/agou-dsh-plugins) 仓库，在插件管理器中通过本包目录的绝对路径安装。

# <img src="icon.svg#svgView(viewBox(6.8,6,35.0625,31.875))" alt="Installed Plugins First icon" width="40" height="36" align="absmiddle" /> Installed Plugins First

<sup>**English** | [中文](README-zh-CN.md)</sup>

Shows installed plugins before built-in experimental plugins on the Installed tab.

The groups appear in this order: built-in plugin configuration, Installed plugins, Experimental plugins. Disable the plugin to restore the original order.

## Install

Requires DSH 0.2.1-rc.5 or later with the Web UI.

```sh
dsh plugin --profile <profile> add dsh-plugin-installed-order
```

From a local clone of [agou-dsh-plugins](https://github.com/agoudbg/agou-dsh-plugins), install this package directory through the DSH Plugin Manager instead.

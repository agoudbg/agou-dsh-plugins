# ![](icon.svg) 滚动条贴边可用

[English](README.md) | **中文**

让滚动条在鼠标位于屏幕边缘时可用。

鼠标贴住窗口右缘时，也能抓住会话页面和文件面板的滚动条。滚动条外观不变，可拖动的范围延伸到了窗口边缘。

## 安装

需要 DSH 0.2.1-rc.5 或更高版本，并使用网页界面。

```sh
dsh plugin --profile <profile> add dsh-scrollbar-edge-hit
```

也可以克隆 [agou-dsh-plugins](https://github.com/agoudbg/agou-dsh-plugins) 仓库，在插件管理器中通过本包目录的绝对路径安装。

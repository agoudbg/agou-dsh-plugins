- Sources: plugin behavior lives in `packages/<name>/index.js` (host half), `client.js` (web half), and `cordis.patch.yml`; user-visible strings in `packages/<name>/locale/en.json` and `locale/zh.json` (`meta.title`, `meta.description`, runtime dictionaries); icons at `packages/<name>/icon.svg`.
- Docs repo: this repository. Each plugin's user documentation is `packages/<name>/README.md` (English) and `packages/<name>/README-zh-CN.md` (Simplified Chinese) for GitHub; the DSH plugin page shows the generated `DETAIL.md` / `DETAIL-zh-CN.md` named by `meta.detail` in the matching `locale/<language>.json`, falling back to the English one.
- Format: plain Markdown, no frontmatter. The README opens with a heading line `# <img src="icon.svg#svgView(viewBox(...))" ... /> <display title>` using the locale title and the same crop viewBox as the root README plugin list (width 40, height 36, absmiddle), then a `<sup>` language-switch line (`<sup>**English** | [中文](README-zh-CN.md)</sup>` in English docs, `<sup>[English](README.md) | **中文**</sup>` in Chinese docs), then the locale `meta.description` sentence on one line, then the body. Keep docs brief: what it does, install, configuration when the plugin has settings. Raw HTML is dropped by the DSH renderer and relative links render as plain text there, so the header lives only in the READMEs; `DETAIL*.md` files are generated from the body under the header (the page already shows the icon, name, and description).
- Validation: `node scripts/check-packages.mjs` and `node scripts/check-market-index.mjs` from the repository root (CI runs both). After editing a README, regenerate the detail documents with `node scripts/build-plugin-details.mjs`; the package check fails while a generated copy is stale.
- Screenshots: launch the DSH Web GUI (`dsh web`) and capture with `playwright-cli` from the URL it prints; the page rejects other URLs. Plugin docs currently use no screenshots.
- Language: docs in English and Simplified Chinese; DSH UI in English or Simplified Chinese. Quote UI labels in the reader's language; when the exact UI string is unverified, describe the control without quoting.
- Conventions: no internal identifiers (service names, selectors, storage keys, slot names); no version-bump or release notes in plugin docs; Conventional Commits; `market/index.json` is generated, never edited by hand.
